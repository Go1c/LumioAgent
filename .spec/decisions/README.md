# Decisions(框架决策记录 · ADR)

**框架级 / 跨功能决策**的记录地:为什么这样调度、为什么定这种结构、为什么划这条边界。功能内的产品决策**不在这里**——写各 feature 文档的「已决策」。

- 一个决策 = 一个文件:`NNNN-<slug>.md`,编号递增,**决策一旦记录不改写**——被推翻就新增一条 ADR 标注取代关系,历史留痕。
- 无 frontmatter。头部固定三行:标题、日期、状态(`生效` / `被 NNNN 取代`)。
- 正文三节:**背景**(面对什么问题)、**决策**(定了什么)、**后果**(接受了什么代价)。
