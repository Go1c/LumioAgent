# Standards（规范支）

学科级详细规范：稳定、跨功能、要遵守。和 `rules/` 的区别——**rules 管“禁止碰什么”，standards 管“怎么做”**。
学科只有一套时直接平铺文档；多学科再用 `<学科>/` 子目录分（内容厚了才下分）。

## 下钻

- **workflow** — 分支 / 提交 / 合并·PR 流程；动手改代码前查 — 状态: 草稿 — [workflow.md](./workflow.md)
- **code-style** — 注释 / 命名约定；写代码时查 — 状态: 草稿 — [code-style.md](./code-style.md)
- **testing** — 何时走 TDD / 验收 DoD；实现功能 / 修 bug 时查 — 状态: 草稿 — [testing.md](./testing.md)
